# Signals fundamentals lab

## Download the lab files

Download these two files into the same folder:

- [Student notebook](https://raw.githubusercontent.com/t0nyliang/GuaqBand/main/notebooks/signals_basics/signals_basics_coding_challenges.ipynb)
- [Requirements](https://raw.githubusercontent.com/t0nyliang/GuaqBand/main/notebooks/signals_basics/requirements.txt)

## Install and run

Open a terminal in the folder containing both downloaded files. On macOS or Linux, run:

```bash
python3 -m pip install -r requirements.txt
python3 -m jupyter lab signals_basics_coding_challenges.ipynb
```

On Windows, replace `python3` with `python` in the commands above. Jupyter opens the notebook in your browser. Run cells from top to bottom. Complete the functions marked `TODO`, then rerun their checks and plots.
